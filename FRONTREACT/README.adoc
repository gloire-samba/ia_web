== 📖 Objectif du module
Ce dossier contient l'interface graphique de l'application, développée avec la bibliothèque **React** (propulsée par **Vite**).
Son rôle est de fournir une expérience utilisateur (UX) fluide et interactive, sous la forme d'un chat conversationnel, agissant comme un clone parfait de la version Angular.

Il permet à l'utilisateur de :
* Saisir des requêtes textuelles.
* Joindre des fichiers (PDF, Word, Excel, images).
* Basculer dynamiquement entre le serveur relais Java (Spring Boot) et le serveur Python (Django) grâce à un simple bouton.
* Naviguer vers l'interface Angular en un clic.
* Afficher les réponses de l'IA de manière esthétique et gérer les erreurs de connexion (surcharge des serveurs, etc.).

== 🏗️ Fichiers clés et Architecture
L'application a été construite autour d'une architecture moderne React/TypeScript, optimisée par Vite, et préparée pour le déploiement par conteneur :

* `src/models/` : Contient les interfaces de données TypeScript (`chat-request.ts`, `chat-response.ts`, `message.ts`).
* `src/services/chat.service.ts` : Le "facteur" de l'application. C'est ce fichier qui gère les requêtes HTTP (via l'API standard `fetch`) vers les serveurs relais locaux.
* `src/components/` : Contient le composant visuel principal `Chat.tsx` (JSX, logique d'état avec les Hooks) et son style `Chat.css`.
* `src/App.tsx` et `src/main.tsx` : Les points d'entrée gérant le routage (React Router) et l'initialisation de l'application.
* 🐳 **`Dockerfile`** : Le script de construction Docker. Il utilise une approche "multi-stage" : il compile l'application rapidement avec Vite, puis sert les fichiers statiques générés (dossier `dist`) via un serveur web **Nginx** ultra-léger et performant.
* ⚙️ **`nginx.conf`** : La configuration du serveur Nginx. Elle est indispensable pour gérer le routage interne de React (Single Page Application) et éviter les erreurs 404 lors du rafraîchissement des pages.

== 🔒 Note sur la sécurité
Ce module Front-end ne contient **aucune clé API Google ni aucune URL Hugging Face**.
Il est conçu pour communiquer exclusivement avec les serveurs relais locaux.
C'est une mesure de sécurité (séparation des préoccupations) empêchant toute fuite de clés publiques côté client.

== 🚀 Comment lancer le Front-end React ?

Vous avez deux méthodes pour lancer l'interface : de manière isolée via Docker (pour la production locale) ou manuellement (pour le développement).

=== Méthode 1 : Lancement autonome avec Docker (Recommandé)
Cette méthode permet de tester le Front-end compilé avec Nginx, sans avoir besoin d'installer Node.js sur votre machine.
_Prérequis : Avoir Docker installé et démarré._

. Ouvrez un terminal dans le sous-dossier contenant le fichier `Dockerfile` (dans `FRONTREACT/front-react`).
. Construisez l'image Docker de l'interface :
+
[source,bash]
----
docker build -t ia-frontend-react .
----
. Démarrez le conteneur en liant le port 80 de Nginx au port 5173 de votre machine :
+
[source,bash]
----
docker run -p 5173:80 ia-frontend-react
----
L'interface React est accessible sur **http://localhost:5173**.

=== Méthode 2 : Lancement manuel de développement
Cette méthode est idéale si vous souhaitez modifier le code React et voir les changements en temps réel (Hot Reloading ultra-rapide de Vite).
_Prérequis : Node.js (v24+)._

. Ouvrez un terminal dans le sous-dossier `FRONTREACT/front-react`.
. Installez les dépendances : `npm install`
. Démarrez le serveur de développement : `npm run dev`
L'interface est accessible sur **http://localhost:5173**.

---
⚠️ **Attention : Quel que soit le mode de lancement, l'interface s'ouvrira, mais pour que le chat fonctionne, vous devez impérativement lancer l'un des serveurs relais (Spring Boot ou Django) et sélectionner le bon bouton dans l'interface !**

Vous trouverez ci-dessous les liens directs pour gérer vos serveurs relais :

== 🛑 Comment arrêter le Front-end ?
* **Si lancé avec Docker (Méthode 1) :** Dans le terminal où tourne le conteneur, appuyez sur **`Ctrl + C`**.
* **Si lancé manuellement (Méthode 2) :** Dans le terminal où tourne la commande `npm run dev`, appuyez simultanément sur **`Ctrl + C`**.
